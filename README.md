# FRAGNIVO

Website for FRAGNIVO, a fragrance shop in Sri Lanka selling full bottles and 10 ml decants.

- **Preview locally:** double-click `Start Site.bat`, then open http://localhost:8080
- **Change prices, contact details or perfume text:** edit `js/data.js`
- **Publish changes:** run `Build Site.bat`, which rebuilds the `docs` folder, then push to GitHub

GitHub Pages serves the `docs` folder.

Before launch, set `previewMode` to `false` and `siteUrl` to the real web address in `js/data.js`.
